## เขียนยังไงให้ใช้ได้จริง

- **อาการ → สาเหตุ → วิธีแก้** เป็นลำดับ อย่าข้ามสาเหตุ
- ใส่ **ข้อความ error จริง** ไม่ใช่คำบรรยาย คนจะได้ค้นเจอ
- อ้าง **commit** ที่แก้ เพื่อให้ไล่ย้อนได้โดยไม่ต้องเชื่อสรุป
- ระบุว่า **อะไรยังไม่ได้แก้และเพราะอะไร** สำคัญพอ ๆ กับสิ่งที่แก้แล้ว
- เขียนคำสั่ง **ตรวจสถานะปัจจุบัน** ไว้ด้วย เพราะข้อมูลในเอกสารจะเก่าไปตามเวลา
